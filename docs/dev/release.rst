Releasing TAPA Builds
=====================

.. note::

   This section explains how to release TAPA builds. It is intended for
   **maintainers** with write access to the TAPA repository.

Releases are published on GitHub at
`github.com/tuna/tapa/releases <https://github.com/tuna/tapa/releases>`_.
Tag a new version in the `TAPA repository <https://github.com/tuna/tapa>`_
and use its release workflow to build and publish the distribution
tarball, then mark the release as the latest stable version.
